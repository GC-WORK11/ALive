## Files changed (lane-owned)
- `server/v2/search.py` — `_merge`: the anchor vouch/namesake machinery now runs only when a locality-family anchor (`_anchor_w>=2`) exists or the query still asks something the anchors didn't claim. - `server/tests/test_v2.py`, `tests/test_v2_explore.py`, `tests/test_purest_oct11.py` — the playtime/purest seeds now place the dip relative to `now` (fixed slots 30-39 fell outside the served next-24h window early in the UTC day — the old comment's claim was false for ~7 h/day); +3 tests: generic-name demote, AC same-name collapse, merge_results junk/dedupe/partial rules.

## Patches needed in files not mine
1. `server/webapp/app.js` — `geo.locate()`: `tm` only calls `end()` when a fix exists; a denied-but-silent provider or a coarse fix that never reaches `goodM` leaves the promise pending forever (the 15 s API timeout error is ignored once `best` is set). Add a hard deadline: `const tm2 = setTimeout(() => end(Object.assign(new Error('timeout'),{code:3})), (opts&&opts.timeoutMs)||15000);` and `clearTimeout(tm2)` in `end()`. The `chooseGps` race in home.js masks the hang but the underlying promise still leaks.
2. `server/main.py` `/v2/feedback` — `raise HTTPException(429, ...)` sends no `Retry-After`; the client can't back off correctly. `raise HTTPException(429, "feedback rate limit — try later", headers={"Retry-After": str(int(3600 - (now - hits[0])))})`.
3. `server/ingest_dpcc.py` — `_bundle_from_pages` emits `"name": label` verbatim, so nav labels like `'SPM-SPC Talkatora Garden'` (and `'SBV Delhi Cantt'`) surface agency codes to users.
